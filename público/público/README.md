# Sistema de Gestión Hotelera

Aplicación web funcional para la gestión de habitaciones, huéspedes y reservas de un hotel (incluyendo registro de reserva y control de salida/check-out), desarrollada con Node.js, Express y Supabase.

## Tecnologías utilizadas
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js + Express
- **Base de datos:** Supabase (PostgreSQL)
- **Despliegue:** Render
- **Control de versiones:** GitHub
